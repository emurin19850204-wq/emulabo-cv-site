# CMS編集不能の復旧記録

確認日: 2026-08-21

ライブプレビューは、画面幅が狭いときに全画面パネルとして開くため、開いたままでは背後の編集フォームを操作できなかった。実行時エラーや認可エラーではなく、プレビューの表示方式による操作上の競合であることを確認した。

修正後は、十分に幅の広いPCだけで編集フォームとプレビューを横並びにする。タブレット・スマートフォンなど横幅が限られる画面では、プレビューの上部に **編集に戻る** ボタンを常時表示し、編集フォームへ明確に戻れるようにした。トップ編集フォームでは、ライブプレビューを閉じた状態で入力欄に一時テキストを入力でき、画面再読込で保存されずに元へ戻ることを確認した。

幅の広いPCでは、ライブプレビューを開いた状態でもトップのアイブロウ入力欄に一時テキストを入力できることを確認した。確認用の入力は保存せず、画面再読込後に元の公開済み値へ戻ることを確認している。

最終確認として `pnpm test` は10件、`pnpm build` は成功した。
