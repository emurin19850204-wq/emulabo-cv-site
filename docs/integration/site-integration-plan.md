# EMULABO 統合サイト設計

## 統合方針

既存のB2B相談獲得サイトを捨てず、法人向けの「教育・現場・運用・AI」支援の深さを主軸に維持する。一方で、emulabo.comの「伴走型」ブランド、個人向けトレーニング、相談前の不安を解消するFAQ、資料・初回体験への目的別CTAを、同じブランド体験に統合する。

## 公開導線

| 入口 | 遷移先 | 読了後の主要CTA | CMSの編集場所 |
|---|---|---|---|
| 法人のお客様 | `/corporate` | 無料オンライン相談／法人向け資料 | 追加ページ・ホームCMS |
| 個人のお客様 | `/personal` | 初回体験を申し込む | 追加ページ・ホームCMS |
| 支援内容 | ホームの法人向け支援セクション | 無料オンライン相談／資料 | ホームCMS |
| ブログ・動画 | `/blog`、`/videos` | 関連する相談 | ブログ・動画CMS |
| プロフィール・FAQ | ホーム内セクション | 無料オンライン相談 | ホームCMS |

## ページ責務

| ページ | 目的 | 編集範囲 |
|---|---|---|
| `/` | EMULABOの共通理念、法人／個人の分岐、法人支援の深さ、信頼、知識導線を伝える | ホームCMS、リンクCMS、ブログ・動画CMS |
| `/corporate` | 法人・同業者の課題、3サービス、期待できる変化、相談・資料CTAを伝える | 追加ページCMS |
| `/personal` | 個人の身体・習慣の課題、伴走型トレーニングの対象・内容・提供方法、初回体験CTAを伝える | 追加ページCMS |
| `/blog`・`/videos` | 信頼形成と相談前の理解を深める | ブログ・動画CMS |
| `/admin` | ホームの内容と画像を変更する | 管理者のみ |
| `/admin/pages` | 法人／個人ページ、ヘッダー・フッターリンクを変更する | 管理者のみ |

## ホームCMS拡張

ホームの既存JSONに以下を追加する。

| 項目 | 内容 |
|---|---|
| `audiences.corporate` | ラベル、見出し、説明、リンク先、CTAラベル |
| `audiences.personal` | ラベル、見出し、説明、リンク先、CTAラベル |
| `resources.corporate` | 法人向け資料CTAのラベル・URL |
| `resources.personal` | 初回体験CTAのラベル・URL |

これにより、トップページの二入口と支援内容セクションの資料導線を、管理画面で安全に変更できる。法人・個人ページそのものは既存の追加ページCMSで管理するため、新しいDBテーブルは不要とする。

## コンテンツ取扱い

`https://emulabo.com/` から確認した既存の公開済みの法人・個人向け説明、FAQ、プロフィールの表現を、統合先の初期コンテンツとして整理する。ユーザーから提供されていないブログ本文、動画URL、口コミ・評価は生成しない。資料URL・申込URLは初期値として既存公開URLを参照できるが、公開前に管理画面で確認・変更できる状態にする。

## 受入基準

- ホームの法人／個人カードがそれぞれ公開済みの専用ページに遷移する。
- `/corporate` と `/personal` は管理画面から本文、画像、CTA、公開状態を変更できる。
- 法人の資料CTAと個人の初回体験CTAは、リンク先が空欄の場合は画面に表示されない。
- 既存のブログ・動画・プロフィール・FAQ・無料相談への導線が損なわれない。
- PCとモバイルでナビゲーション、CTA、追加ページが閲覧可能である。
