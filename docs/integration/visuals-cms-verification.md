# 図表・インフォグラフィックCMSの確認記録

確認日: 2026-08-21

`/admin/visuals` に図表管理画面を追加した。管理者は、図表の追加、画像選択、見出し・説明、種類、表示場所、公開状態、並び順、削除を一つの画面から扱える。トップページ、`/corporate`、`/personal`、および管理済み追加ページを表示先として選択できる。

図表データは既存のトップCMS JSONに `visuals` 配列として保存されるため、既存のCMSデータや公開ページを壊さない。公開ページは、`isPublished=true` かつ画像URLが設定された図表だけを表示する。未登録時はページに図表セクションを表示せず、既存ページの見た目を維持する。

管理画面では、空状態から **図表を追加** を押すと、見出し、図表の種類、説明、表示する場所、画像選択、公開切替、上／下移動、削除の各操作が表示されることを確認した。検証用に作成した未保存の空図表は削除し、公開コンテンツは変更していない。390px幅でも「図表を追加」と「変更を保存」の導線が収まることを確認した。
