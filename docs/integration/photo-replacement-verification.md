# 写真差し替え簡略化の確認記録

確認日: 2026-08-21

管理者として `/admin` を開き、ヒーロー画像を含む全画像欄で、通常表示が **「写真を選ぶ」** ボタン、現在の写真、大きな3操作案内、折りたたまれた **「詳しい設定・確認」** に整理されていることを確認した。URL入力、代替テキスト、推奨サイズ、元写真との詳細比較は通常画面から外し、必要時だけ確認できる構成である。

確認した通常操作は、**写真を選ぶ → 新しい写真を確認して「この写真を使う」→ ページ下部の「変更を保存」** である。写真を選んだだけでは公開サイトの画像は変わらない。

既存の検証画像を使い、ヒーロー画像で写真選択を実行した。アップロード完了後に新しい写真と **「この写真を使う」** ボタンが表示され、確定後には **「元の写真に戻す」** ボタンへ切り替わることを確認した。続けて元に戻す操作を実行し、元のヒーロー写真へ復帰した。ページ全体の **「変更を保存」** は実行していないため、公開サイトとDBの画像設定は変更していない。

390px幅の管理画面でも、ページ上部の編集案内と保存ボタンが収まり、写真の差し替えがページ保存と分離される状態を確認した。

共通画像フィールドは、トップ編集、追加ページ、ブログ、動画の4つのCMS画面で共有されていることを確認した。最終確認として `pnpm test` は10件、`pnpm build` は成功した。
