# EMULABO 統合サイト資産棚卸し（2026-08-20）

## 目的

既存のCMSサイトを基盤として、`https://emulabo.com/` が持つブランドの主張、法人・個人向けの導線、サービス説明、FAQ、資料・相談CTA、プロフィールを、一つの運用可能な公式サイトに統合する。

## 現行 emulabo.com から統合する公開情報

| 領域 | 統合する要素 | 取り扱い |
|---|---|---|
| ブランド | 「伴走型」教育・トレーニング支援、「知って終わり」をなくすという理念 | ホームのブランド導入・考え方で一貫して訴求する |
| 導線 | 法人のお客様／個人のお客様の二入口 | 入口カードから各専用ページへ遷移させる |
| 法人サービス | 法人研修・セミナー、育成・仕組み化支援、中長期サポート運用 | 法人ページに課題・内容・得られる成果・CTAを整理する |
| 個人サービス | 伴走型パーソナルトレーニング、対面・オンライン対応 | 個人ページに対象・内容・提供方法・初回体験CTAを整理する |
| 信頼 | 代表プロフィール、実績、資格 | CMS管理のプロフィール・実績と連携する |
| FAQ | 法人・個人で異なる相談前の不安 | カテゴリー別FAQをCMSで編集可能にする |
| CTA | 無料オンライン相談、法人向け資料、初回体験、お問い合わせ | URLごとにCMS編集可能にし、誤ったリンクは公開しない |

## 既存CMSサイトから維持・強化する機能

| 機能 | 維持または強化方針 |
|---|---|
| CMS | ヒーロー・画像・実績・プロフィール・FAQ・CTAに加え、統合後の法人／個人の導線とページを管理対象にする |
| 相談導線 | 相談への入口を共通化し、法人・個人の目的に応じてラベルを変えて遷移させる |
| ブログ・動画 | 既存の下書き／公開運用を維持し、ナビゲーションと関連導線で統合する |
| 追加ページ | 法人／個人の説明ページを既存の追加ページ機能に収め、管理者が変更可能にする |
| デザイン | 現行の深いネイビーとブルーの設計品質を保ち、写真・人・現場の印象を強める |

## コンテンツ安全性

- ユーザーが未提供のブログ本文、動画URL、顧客レビュー、評価、導入実績は新規に創作しない。
- 法人資料PDFおよび申込URLは、管理者が利用許諾・内容確認済みのURLだけを公開用CTAへ登録する。
