# AI初心者向け画像変更フロー

## 目的

画像を変更する人が、画像URL、ファイル形式、代替テキスト、公開タイミングを事前に理解していなくても、画面に表示された順番どおりに進めるだけで安全に差し替えられる状態を作る。

## 画面上の3ステップ

| 手順 | 画面上の案内 | 操作後に確認すること |
| --- | --- | --- |
| 1. 選ぶ | 「画像を選択」を押し、スマートフォンまたはパソコンから1枚選ぶ。 | 顔や重要な文字が切れていない写真を選ぶ。 |
| 2. 確認する | 現在の公開画像と、選んだ新しい画像を並べて確認する。 | 用途に合う、見切れがない、内容を説明する代替テキストがある。 |
| 3. 保存する | チェックを付け、ページ全体の「変更を保存」を押す。 | 保存後に公開サイトを開いて表示を確認する。 |

## 安全策

新しい画像のアップロードに失敗しても、公開済みの画像URLは変更しない。比較プレビューを表示しても、ページ全体の保存前は公開画面を変更しない。初心者が間違えても「現在の公開画像に戻す」を選べるようにする。

## 写真選びの案内

各画像フィールドには、用途別の説明を表示する。例えばヒーロー画像では「横長で、文字を重ねても顔が隠れにくい写真」、プロフィール画像では「本人または支援中の様子が伝わる写真」、ブログ・動画では「記事や動画の内容がひと目で分かる写真」を案内する。詳細なURL入力は「詳しい設定」にまとめ、通常操作では表示しない。

## 実機確認

`/admin`で、各画像フィールドに3ステップ案内、用途別の写真選びガイド、現在の公開画像、詳細設定、保存前チェックが表示されることを確認した。検証用JPEGを選択すると、現在の公開画像と新しく選んだ画像の比較プレビュー、元に戻す操作、ページ全体の保存前には公開サイトが変わらない案内が表示された。検証用の変更は公開保存を行っていない。

追加ページの `/admin/pages` でも、アイキャッチ画像に同じ3ステップ案内、用途別の選び方、画像の説明入力、保存前チェック、詳細設定が表示されることを確認した。ホーム `/admin` と追加ページの両方で、通常操作にURL入力を要求しない画面構成になっている。

`/admin/blog` の新規記事作成画面でも、アイキャッチ画像に同じ3ステップ案内、画像未選択時のプレビュー、画像の説明入力、写真選びガイド、保存前案内が表示されることを確認した。検証用の記事は保存していない。

`/admin/videos` の新規動画作成画面でも、サムネイル画像に同じ3ステップ案内、画像未選択時のプレビュー、画像の説明入力、用途に合う写真の例、保存前案内が表示されることを確認した。検証用の動画は保存していない。

ヒーロー、プロフィール、相談・研修・運用画像について、管理画面の写真選びガイドに「おすすめの大きさ」と「切れないための注意」が表示されることを確認した。ヒーローは横1920×縦1080以上・16:9、プロフィールは横1200×縦1500以上・4:5、その他の現場画像は横1600×縦1000以上を案内している。CMS利用ガイドにも同じ基準を表で記載した。
