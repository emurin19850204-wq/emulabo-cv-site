# CMSライブプレビューの確認記録

確認日: 2026-08-21

トップ編集画面 `/admin` で **「画面を見ながら編集」** を押し、編集フォームと公開トップページが同時に表示されることを確認した。プレビューは右側に固定され、上部の更新、別タブで開く、閉じるの各操作を備える。

追加ページ、ブログ、動画では、**公開済み**の対象を一覧から選択した後に同じ操作を利用できる。未保存の入力はプレビューへ即時反映せず、各画面の保存後に更新する方式として、公開前の意図しない反映を防ぐ。下書きのブログ・動画・追加ページではライブプレビューを表示せず、公開してから確認できる案内を出す。

`/admin/pages` では、公開中の `/corporate` ページを選択し、編集欄の **「画面を見ながら編集」** から本文・アイキャッチ・CTAを含む公開ページが右側に表示されることを確認した。プレビュー内の更新、別タブ、閉じる操作も表示されている。

390px幅では、ライブプレビューは編集フォームを覆う画面として開く設計であり、編集とプレビューを切り替えて確認できる。

390px幅のトップ編集画面では、上部の案内と **「画面を見ながら編集」** ボタン、固定の **「変更を保存」** ボタンが画面内に収まることを確認した。最終確認として `pnpm test` は10件、`pnpm build` は成功した。
