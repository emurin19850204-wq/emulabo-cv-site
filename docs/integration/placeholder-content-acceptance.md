# 仮コンテンツによる最終受入確認

## 目的

本書で定める仮ブログ記事と仮動画は、CMSの保存、編集、公開制御、公開ページ表示、動画再生を確認するためだけに使用する。実績、顧客情報、利用者の声、導入効果、料金、提供範囲を表すものではない。

| 項目 | 方針 |
| --- | --- |
| 表示名 | タイトル・概要・本文の先頭に「受入確認用の仮コンテンツ」と明記する。 |
| 記事内容 | CMSの動作確認手順のみを記載し、事実と誤認される成果・レビューを含めない。 |
| 動画 | 再生確認専用の公開サンプル動画を使用し、EMULABOの制作物ではないことを明記する。 |
| 公開状態 | 下書き保存後に一時公開して動作を確認し、確認完了後は非公開へ戻す。 |
| 最終状態 | 管理画面で削除または実コンテンツへの置換ができる非公開状態として残す。 |

## 受入手順

まず、仮記事と仮動画を下書きとして保存する。次に一覧への非表示を確認してから一時公開し、一覧、詳細、再編集、動画再生をPCとモバイルで確認する。最後に両方を非公開へ戻し、公開一覧から消えることを確認する。

> 仮コンテンツは、実コンテンツを用意できた時点で管理画面から削除するか、実データで上書きする。
